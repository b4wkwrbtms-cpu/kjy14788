# 말씀 웹소설체 기준서 (곽준영 키우기 · 성경 읽기 '20대 말투')

## 0. 한 줄 목표
개역한글 성경 66권 31,103절을, **20대가 친구한테 이야기해 주듯 쭉쭉 읽히는 한국어**로 다시 쓴다.
**뜻은 원어(히브리어·아람어·헬라어)에서 한 글자도 벗어나지 않는다.** 바꾸는 것은 말투 · 문장 길이 · 줄 나눔 · 소제목뿐이다.
기존 현대어 번역(새번역·쉬운성경·현대인의성경 등)을 가져오거나 흉내 내지 않는다. 원어를 직접 보고, 우리 말투로 새로 쓴다.

## 1. 지키는 것 (내용) — 절대 규칙
1. **절 수 = 개역한글 절 수.** 각 절에는 그 절의 내용만 넣는다. 한국어 어순 때문에 꼭 필요할 때만 앞뒤 절과 문장을 이어 쓴다(예: 창 1:14-15처럼 대사가 다음 절로 이어짐).
2. **더하지 않는다.** 감정·속마음·효과음·배경 묘사·해설·교훈을 새로 넣지 않는다. 허용되는 것은 딱 셋:
   - 괄호 풀이: 단위 `규빗(약 45cm)`, 제사 용어 `번제물(통째로 태워 바치는 제물)`, 이름 뜻 `여호와 이레(여호와가 마련하신다)` — 그 장에서 처음 나올 때 한 번만.
   - 원어에 담긴 주어·대상을 밝히기 (히브리어 동사 속 주어, '그가'가 누구인지 헷갈릴 때 이름으로).
   - 연결어(그리고, 그때, 그런데)를 원문 흐름에 맞게 고르기 (히브리어 '와우'를 매번 '그리고'로 옮기지 않음).
3. **빼지 않는다.** 모든 사람·땅 이름, 숫자, 조건, 목록, 반복구(“저녁이 되고, 아침이 되었다”)를 그대로 둔다. 반복은 원문의 리듬이다.
4. **숫자는 정확히.** 나이·인원·치수·날짜를 바꾸지 않는다.
5. **원어가 개역한글과 다르면 원어를 따른다.** 주어(창 22:2 개역 '여호와께서' → 원어 '그(하나님)가'), 단수·복수(창 22:5 '우리가 돌아오리라'), 시제, 하나님 이름(아래 6절).
6. **사본에 없는 절**(원어 칸에 '사본에 없는 절')도 빼지 않고 개역한글 뜻대로 옮긴다.
7. **사람 이름은 개역한글 표기 그대로** (아브라함, 므두셀라, 여호사밧 …). 비판본 헬라어 철자가 달라도(마 1:7 Ἀσάφ) 개역 이름을 쓴다.
8. **핵심 신앙 용어는 바꾸지 않는다** — 은혜, 죄, 구원, 믿음, 회개, 성령, 언약, 속죄, 거룩, 영광, 복음, 하나님 나라. 풀어 쓰더라도 이 낱말은 남긴다.

### 2-2. 쓰는 기법
1. **모바일 문단.** 한 줄(= "\n"로 나눈 한 덩어리)은 1~2문장. 대사는 반드시 자기 줄.
2. **짧은 문장, 한 문장에 정보 하나.** 개역의 '~하고 ~하며 ~하니' 이어 붙인 문장을 끊는다(같은 절 안에서).
3. **바로 사건.** '그 일 후에', '그때에'는 짧게. 서술 군더더기('이에', '곧', '그런즉')는 뺀다(뜻 없는 연결어만).
4. **종결어미 리듬.** 서술은 '-했다/-였다/-다'를 기본으로, 같은 어미가 세 번 넘게 이어지면 문장 길이를 바꾼다.
5. **강조 한 줄.** 원문에서 이야기의 정점인 문장(창 22:10 '아들을 죽이려고.', 창 1:31 '보니, 정말 좋았다.')은 자기 줄로 떼어 놓는다. 원문에 있는 문장만.
6. **소제목 = 회차 제목.** 장마다 1~6개, 짧고 끌리게(4~14자). 사건을 요약하되 스포일러로 결말을 미리 말하지 않고, 원문에 없는 내용을 암시하지 않는다.
   좋은 예: '모리아로 가라', '칼을 든 순간', '약혼녀가 임신했다', '독사 새끼들', '무덤이 비었다'. 나쁜 예: '아브라함의 위대한 믿음'(교훈), '충격 반전!!'(낚시).
   소제목은 긴장이 걸리는 지점(대사 직전, 사건 시작)에서 끊는다.
7. **목록은 줄로.** 족보·인구 조사·지파 경계·성막 재료·문안 인사는 한 줄에 한 항목.
8. **말줄임표(…)·느낌표는 아껴서.** 원문 흐름상 망설임·외침이 분명할 때만.

### 2-3. 쓰지 않는 기법 (내용이 바뀌므로)
1인칭 시점으로 바꾸기 · 상태창/게임 용어 · 서술자 논평('놀랍게도', '안타깝게도') · 속마음 독백 추가 · 효과음('쾅!') · 원문에 없는 문장 ·
인터넷 은어·줄임말·비속어·이모티콘(ㅋㅋ, ㄹㅇ, 개-, 킹받네, 갓생, 레전드…) · 외래어 남발(텐션, 멘탈, 리스펙…).

## 3. 말투 (관계별)
| 누가 → 누구에게 | 말투 | 예 |
|---|---|---|
| 서술(이야기) | 웹소설 과거형 '-했다'. 하나님·예수님·성령·주님(하나님/예수님)에게만 '-시-' | 하나님이 말씀하셨다 · 예수님이 배에 오르셨다 · 다윗이 말했다 |
| 서술의 주격 | '께서' 대신 '이/가' | 하나님이 / 예수님이 |
| 하나님 → 사람 | 위엄 있는 반말(해라체). 약속은 '-겠다', 명령은 '-라/-해라' | “데리고 모리아 땅으로 가라.” “내가 너와 함께 있겠다.” |
| 하나님이 자기를 말할 때 | '나 여호와', '여호와가 말한다' | “나는 여호와다.” |
| 사람 → 하나님(기도·탄원) | 해요체 | “여호와, 왜 이렇게 멀리 계세요?” “제 기도를 들어 주세요.” |
| 예수님 → 제자·군중 | 반말(해라체 + 해체 자연스럽게) | “나를 따라와라.” “걱정하지 마.” “진짜로 말하는데,” |
| 예수님 → 적대자 | 단호한 반말 | “이 위선자들아!” “독사 새끼들아!” |
| 제자·군중 → 예수님 | 해요체(가끔 합니다체) | “선생님, 저희가 죽게 생겼어요!” “주님, 누구에게 가겠어요?” |
| 왕 ↔ 신하 | 왕은 반말, 신하는 합니다체 + 호칭 '전하'(이스라엘·유다 왕) / '폐하'(이집트 파라오·바빌론·페르시아·로마 황제) | “전하, 만수무강하십시오.” |
| 친구·동료·형제끼리 | 반말 | 욥과 세 친구 · 형제들 |
| 부모 → 자녀 | 반말 | “아들아, ~해라.” |
| 자녀 → 부모 | 해요체 | “아버지, ~예요?” |
| 처음 만난 어른·낯선 사람 | 해요체 / 합니다체 | 우물가 대화 |
| 천사 → 사람 | 해라체(하나님의 전령) | “두려워하지 마라.” |
| 예언자 → 백성 | 선포는 해라체('너희는 들어라'), 하나님 말씀 인용 '여호와가 말한다' | |
| 사도·연설 → 군중 | 합니다체 + '여러분' | 사도행전 설교 |
| 서신(바울 등) → 교회 | '여러분' + 해요체 중심, 단호한 대목은 '-습니다/-다' | “형제자매 여러분, 이렇게 부탁해요.” |
| 시편 | 노래 가사체. 하나님에 대해 말할 땐 반말 서정('-야/-네/-셔'), 하나님께 직접 말할 땐 해요체 | 시 23 예시 |
| 잠언 | “아들아, ~해라.” 격언은 한 줄씩, '-다' | |
| 전도서 | 1인칭 혼잣말 에세이 '-다' | “헛되다. 정말 헛되다. 다 헛되다.” |
| 아가 | 연인의 반말 대화, 품위 있게 | “내 사랑, 넌 정말 아름다워.” |
| 계시록 | 1인칭 목격담 '나는 봤다' + 장면 짧게 | |

부르는 말: 여호와여 → '여호와,' · 주여 → '주님,' · 하나님이여 → '하나님,' · 왕이여 → '전하,'/'폐하,' · 선생이여 → '선생님,' · 사람의 이름은 '아브라함아!'처럼 그대로.

## 5. 낱말 바꾸기 (옛말 → 지금 말)
**어미:** 가라사대/가로되/이르되 → 말했다·말씀하셨다 · -하니라/-하더라/-이니라 → -했다/-였다/-이다 · -지어다/-할지니라 → -해라/-해야 한다 · -나이다/-옵소서 → -요/-주세요 · 보라(הִנֵּה·ἰδού) → 대사에선 '봐라,/자,/잘 들어,' 서술에선 '보니'(뺄 수도 있음).

## 6. 갈래별
- **이야기(창세기~에스더, 복음서, 사도행전):** 2-2 기법을 그대로. 대화 장면은 주고받기를 줄마다.
- **율법(레위기·민수기·신명기 규정):** 하나님 → 모세 해라체. '~하면 ~해라' 조건문을 짧게. 반복 정형구(“여호와가 모세에게 말씀하셨다.”)는 유지. 재료·수치 목록은 줄로.
- **족보·명단(창 5·10·11·36, 민 1·26, 대상 1~9, 스 2, 느 7 등):** 한 줄에 한 사람 · 한 집안. “셋은 105살에 에노스를 낳았다.” 인원은 아라비아 숫자.
- **시(시편·잠언·아가·애가·욥기 대화·예언서 시):** 히브리 시행 하나 = 한 줄. 노래 가사처럼. 평행구(같은 말 두 번)는 살린다. 표제는 1절 첫 줄 〔다윗의 노래. 지휘자를 따라〕 처럼(원어 1절에 표제가 있으면).
- **예언서:** “여호와가 말한다.” 선포는 짧고 세게. '그날에' 같은 표지는 줄 앞에.
- **서신:** 편지처럼. 길게 이어진 바울의 문장(엡 1:3-14 등)은 절 안에서 짧게 끊는다. 논리 접속어(그러니까, 그런데, 왜냐하면)는 살린다. 문안 인사는 줄로.
- **묵시(다니엘 7~12, 계시록):** 본 것을 한 장면씩. 숫자·색·재료 정확히.

## 7. 출력 형식
파일: `bout/BB/CCC.json` (BB = 권 번호 두 자리, CCC = 장 세 자리)
```json
{"b": 1, "c": 22, "h": [[1, "모리아로 가라"], [9, "칼을 든 순간"]], "v": ["1절 첫 줄\n둘째 줄", "2절", "…"]}
```
- `v` 길이 = 개역한글 절 수. 줄바꿈은 `\n`. 큰따옴표는 “ ”, 작은따옴표는 ‘ ’ (곧은 따옴표 " 금지 — JSON이 깨짐).
- `h` = [[시작 절, 소제목], …] 시작 절 오름차순, 첫 소제목은 보통 1절.
- 계보 이름 표시는 하지 않는다(나중에 규칙으로 자동 표시 · 구약만).
- 구약·신약 모두 이 기준으로 쓴다.
- 다 쓰면 `python3 bcheck.py BB CCC` 로 검사하고, 나온 문제를 고친다. (길이 비율 경고는 시·족보에서 정상일 수 있음 — 확인만.)

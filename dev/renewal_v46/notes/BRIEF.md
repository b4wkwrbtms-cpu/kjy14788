# 해설 카드 말투 통일·반복 정리 — 작업자 지침 (끝까지 읽기)

## 배경
성경 읽기 앱에서 본문 낱말(인물·지명·생활/단위·원어)을 누르면 아래에서 '해설 카드'가 올라온다. 다른 팀이 만든 카드 1,067개를 우리 앱에 넣는데, 말투가 섞여 있고(해요체·합니다체·해라체) 같은 문장이 반복된다. **내용은 그대로 두고 읽기만 매끄럽게** 다듬는다.

## 입력
`/home/claude/renewal/notes/in/{묶음}.jsonl` — 한 줄에 카드 하나:
`{"id","k"(person|place|culture|hebrew),"title","brief"(첫 화면 요약),"heads":[[블록,항목,소제목]],"ps":[[블록,항목,문단,글]]}`

## 할 일
1. **말투를 해요체로 통일**: brief와 모든 문단을 …예요/이에요/해요/있어요/돼요/거예요/봐요 등으로 끝낸다. '-다.'·'-니다.'로 끝나는 문장을 남기지 않는다. 친근하되 가볍지 않게(인터넷 말투·이모티콘·감탄 남발 금지).
2. **반복 지우기**: 첫 블록의 문단이 brief와 같은 문장을 되풀이하면 그 문장을 빼고 나머지만 남긴다(전부 같으면 그 문단은 빈 문자열 ""). 다른 문단끼리 같은 문장이 반복돼도 뒤의 것을 뺀다.
3. **작업 메모 말투 고치기**: "혼동하지 말자", "~로 옮겼다", "편집 해설입니다", "확정하지 않는다" 같은 제작자 말투는 독자에게 하는 설명으로 바꾼다(예: "예언서 미가의 저자와 같은 사람이라고 혼동하지 말자" → "예언서를 쓴 미가와는 다른 사람이에요").
4. **지키는 것**: 사실·숫자·이름·지명·장절 표시·히브리어·한글 발음·학자/설교자 이름과 그들의 견해, 해석이 갈린다는 언급, 불확실성 표시. 새 사실을 더하지 않는다. 문장을 크게 늘리지 않는다(원래 길이 이하 권장).
5. 소제목(heads)은 그대로 둔다(명사형이면 그대로). title도 그대로.

## 출력
`/home/claude/renewal/notes/out/{묶음}.jsonl` — 입력 한 줄마다 한 줄, 같은 순서:
`{"id":"…","brief":"새 요약","ps":[[블록,항목,문단,"새 글 또는 빈 문자열"], …]}` (입력의 ps 개수와 같게, 순서·번호 그대로)
- 카드 5~8개를 처리할 때마다 Bash로 덧붙여 저장(작업이 끊겨도 남게):
  ```
  python3 - <<'PY'
  import json
  rows=[ {...} ]
  with open('/home/claude/renewal/notes/out/n03.jsonl','a',encoding='utf-8') as f:
      for r in rows: f.write(json.dumps(r,ensure_ascii=False)+'\n')
  PY
  ```
- 입력은 Read 도구로 나눠 읽는다. 이미 출력 파일이 있으면 그 줄 수만큼 건너뛰고 이어서 한다.

## 마지막 점검과 최종 답
- Bash(python3)로: 출력 줄 수 = 입력 줄 수, id 순서 같음, 각 카드 ps 개수·번호가 입력과 같음, '다.'·'니다.'로 끝나는 문장이 남았는지 세어 보고(인용문 안은 예외) 고친다.
- 최종 답(6줄 이내): 처리한 카드 수, 지운 반복 문단 수, 남은 예외. 파일 내용을 다시 옮기지 말 것.

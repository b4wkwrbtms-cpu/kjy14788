## 0. 기준
- **집필 기준은 `/home/claude/renewal/notes2/PROMPT_user.txt` (사용자가 준 '해설 집필 전용 프롬프트')다. 처음부터 끝까지 읽고 그대로 따른다.** 아래는 이 앱에 맞춘 추가 결정이다. 충돌하면 아래가 우선한다.
- **말투: 20대 독자용 해요체.** 프롬프트 예시는 합니다체지만 쓰지 않는다. 문장 끝은 -예요/-이에요/-해요/-거예요/-죠 등. 친한 선배가 차근차근 설명하듯 편하고 또렷하게. 인터넷 유행어·이모티콘·과장 감탄 금지. 학자·설교자 이름과 견해는 정확하게.

- 성경 인명·지명은 **개역한글 표기**(사무엘, 엘리, 실로, 벧엘 …). 하나님 이름 YHWH는 '여호와'.
- 본문 인용은 우리 앱의 20대 말투 본문을 쓴다(아래 입력 ②). 다른 한국어 번역 문장을 인용하지 않는다.

## 1. 맡은 카드와 입력
맡은 카드 id 마다:
① 기존 카드: `/home/claude/renewal/notes2/in/{id}.json` (그쪽 팀 원본, 합니다/해라체 섞임. `_target_ref` = 이번에 기준으로 삼을 구절). 기존 내용·출처는 참고 자료이고, 사실은 다시 확인한다.
② 우리 본문: `/home/claude/bw/bout/BB/CCC.json` (BB=권 번호 2자리, CCC=장 3자리; v 배열이 절). 앞뒤 문맥도 읽는다.
③ 원어 대조: `/home/claude/bw/bin/BB/CCC.txt` (개역·WEB·원어, 모음 부호 없음). 모음 있는 히브리어: `/home/claude/renewal/app/bible/he/BB.json` (1~12권, 장→절 배열).
④ 원어 형태 정보(어근·동사 형태·인칭·수): biblehub.com 의 interlinear / 낱말 분석 페이지(WebFetch)로 확인한다. (raw.githubusercontent.com 은 이 환경에서 막혀 있음)
⑤ 사전·주석·설교: WebSearch / WebFetch 사용 가능. **한 번에 WebFetch 2개 이하, 429가 나면 30초 쉬고 다시.** 확인하기 쉬운 곳: biblehub.com (히브리어 사전 BDB·Strong, 칼뱅·매튜 헨리·길·스펄전 등 주석), ccel.org (칼뱅 주석, 스펄전 설교), spurgeon.org, gospelinlife.com·timothykeller.com (켈러), 휫필드 설교집. 네이버는 열리지 않으니 우회하지 않는다. **실제로 읽은 범위만 출처에 적는다.** 못 찾으면 지어내지 말고 memo에 '추가 연구 필요'로 남긴다.

## 2. 출력 (카드마다 파일 하나)
`/home/claude/renewal/notes2/out/{id}.json` — Write 도구로, UTF-8 JSON:
```
{
 "id": "...", "k": "hebrew|person|place|culture", "ref": "창세기 2:18",
 "q": "독자가 막히는 질문 (화면 비표시)",
 "title": "장면 속 의미가 드러나는 짧은 제목",
 "expr": [["원어 표기(모음 포함)", "한글 발음", "이 구절에서의 뜻"]],   // 인물·지명·단위도 원어 이름을 넣는다
 "core": "독자가 기억할 한 문장",
 "body": ["문단1", "문단2", "문단3"],          // 본문 해설 2~3문단(더 필요하면 4), 표지 없이 이어지는 글
 "deep": [ {"h": "실제 용례와 당시 배경", "p": ["…"]},
           {"h": "시제·문법이 보여 주는 의미", "p": ["…"]},
           {"h": "설교자·주석가의 관점", "p": ["…"]},
           {"h": "다른 해석과 판단 근거", "p": ["…"]} ],   // 이 카드에 필요한 것만, 순서 유지
 "src": [ {"t": "저자 · 자료명 · 본문/쪽/단락 · 실제 확인한 범위", "u": "https://… (없으면 빈 문자열)"} ],
 "memo": "편집자 확인 사항 (독자 비표시): 확인 못 한 점, 해석적 추론, 추가 연구거리"
}
```
- 히브리어는 모음 부호가 있는 형태로(입력 ③의 he 파일 또는 사전에서 확인).
- 설교자 관점 한 항목은 프롬프트 8절 구조(누구·어느 자료 → 무엇을 강조 → 본문 근거 → 본문 의미와 적용의 경계 → 독자에게 주는 이해)로 3~5문장 이상.
- 직접 인용은 원문을 실제로 읽은 경우에만, 그 외는 '요약'임을 src 에 밝힌다.


## 5. 본문 확인 표시 (사용자 요청 10-18 — 반드시)
- 카드를 쓰다가 **우리 앱 본문(bout)이 원어 또는 주석 다수와 다르게 읽은 곳**, 본문 안에서 같은 말을 다르게 옮긴 곳(용어 불일치), 이름·표기가 앞뒤로 다른 곳을 발견하면, 출력 JSON에 `"tq"` 배열을 넣는다:
  `"tq": [{"ref":"왕하 15:5","now":"앱 본문 표현","why":"원문/주석 다수는 어떻게 읽는지 + 근거 한 줄","sug":"고친다면 이렇게"}]`
- 없으면 `"tq": []`. 애매한 해석 차이(주석이 반반 갈림)는 넣지 말고 카드 안에서만 다룬다. 사용자가 이 목록으로 본문을 한꺼번에 고친다.

## 4. 대량 작업 규칙 (10-18, 시범 승인 뒤)
- 기준 구절은 입력의 `_target_ref`(기존 카드 loc의 첫 주소). 주소가 애매하면 기존 카드 내용으로 판단한다.
- 맡은 카드마다 **끝나는 즉시** out 파일을 쓴다. 이미 out 파일이 있는 카드는 건너뛴다(이어 하기).
- 조사 강도: 원어·신학 표현 카드는 설교자·주석가 관점까지 조사한다. 인물·지명·생활 카드는 프롬프트 9절대로 이해에 필요한 만큼만(설교자 관점은 그 본문을 직접 다룬 확인 자료가 쉽게 나올 때만). 한 카드에 WebFetch는 대략 6번 안팎.
- 시범 카드 `/home/claude/renewal/notes2/out/gen-ezer.json` 하나를 먼저 읽고 수준·말투를 맞춘다.

## 6. bible-renewal-suite 스킬 반영 (10-24, 사용자 요청) — 8차부터
사용자가 준 스킬(/home/claude/skill_brs/bible-renewal-suite)의 원칙을 적용한다. PROMPT_user.txt와 같은 방향이고, 아래만 더한다.
- **연구 순서(바꾸지 말 것)**: 본문(장 전체) → 구조 → 원어(번역이 갈리는 절에만 깊게) → 관련 구절(실제로 읽고 인용) → 역사·생활 배경 → 주석·설교는 **맨 마지막**. 주석을 먼저 읽고 그 결론을 받아 적지 않는다.
- **주석은 서로 다른 전통 2~3개**(예: 칼뱅·매튜 헨리(청교도)·존 길·애덤 클라크(웨슬리안)·카일-델리치(루터파, 구약)·JFB). 갈리면 갈린다고, 누가 무엇에 근거하는지 쓴다. 평균 낸 '가짜 합의'를 만들지 않는다.
- **세 층을 섞지 않는다**: ① 본문이 말하는 것(주소와 함께) ② 주석가·설교자가 말하는 것(이름을 붙여) ③ 내 추론(본문에서 '~로 볼 수 있어요'처럼 추론임이 드러나게, 근거는 memo에).
- **찾지 못하면 그렇게 쓴다**: 사전·주석·인터리니어 페이지가 비었거나 429로 막혔으면, 기억으로 뜻·연대·형태를 채우지 않는다. 그 내용은 쓰지 않고 memo에 무엇을 못 봤는지(사이트·주소) 적는다. 가까운 번호·비슷한 철자 항목을 그 낱말로 쓰지 않는다.
- **원어 검사**: 해당 절의 실제 형태(접두·접미 포함) → 기본형 → 문장 역할 → 문맥의 뜻. 비교 용례 1~2곳은 같은 기본형인지 확인. 영어·한국어 번역이 같다고 같은 원어라 하지 않는다. 시제·상만으로 '영원히/단 한 번' 같은 결론을 내지 않는다. 어원·본문 말놀이·후대 설교 연상을 구별한다. 인명은 근거 없이 어근 분해하지 않는다.
- **이름·지명·동식물·도량형**: 어원 설명의 확실성 정도를 밝히고 명명 사건·본문 속 역할과 잇는다. 동식물 동정은 불확실성을 표시. 도량형은 단위·금속·환산 가정을 밝히고 현대 금속값과 당시 구매력을 구별한다.
- **설교자·주석가**: 켈러·휫필드로 제한하지 않는다. 국내외·여러 시대·현재 목회자의 공개 원고까지 조사. 그 본문을 직접 다룬 자료와 같은 주제의 다른 설교를 구별. src에 저자·제목·(날짜)·해당 본문·쪽/단락/타임스탬프·URL·**실제 읽은 범위**('소개만 읽음', '요약 도구로 읽음' 등)를 적는다. 못 찾은 사람의 해석은 만들지 않는다.
- **성경 주소 표기(앱 링크용)**: 본문·심화에서 다른 구절을 가리킬 때는 **항상 책 이름을 붙여** 쓴다: '삼상 1:20', '사무엘상 1:20', '출 31:18; 출 34:2'. 책 이름 없는 '1:20', '34:2'는 앱에서 링크가 안 된다. 범위는 '삼하 12:29–31'(같은 장 안에서만).
- 깊이: 자료만 많은 글은 깊은 해설이 아니다. 다 쓰고 나서 '독자가 뜻·이유·장면을 자기 말로 설명할 수 있나'로 다시 읽는다. 일반적인 신앙 권면으로 끝내지 않는다.

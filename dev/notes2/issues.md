# 해설 작업 중 나온 편집 판단 거리 (본문·표기)
- 민 14:24 '끝까지 따랐다' vs 다른 곳 '온전히 따랐다' (같은 관용구) — 통일 필요
- 수 7장 '갈미/아간' vs 대상 2:7 '가르미/아갈' 표기
- 삿 5:7·11 '지도자들/이끄시는' — 주석 다수는 '마을(사람들)' 읽기
- 출 33:11 '말씀하셨다' — 반복형('말씀하시곤 했다') 검토
- 삼상 1:5 본문 '갑절' vs 기존 카드 '특별한 몫'
- 삼상 13:1 본문이 숫자를 채움(마흔 살·이 년) vs 마소라 '한 살… 두 해'
- 삼상 30:17 '새벽부터' vs '해 질 무렵부터' / 31:3 '큰 부상' vs 대상 10:3 '고통에 몸부림쳤다'
- 삼하 2:27 앱 본문이 14절 제안 쪽 읽기
- 삼하 12:24 앱 본문은 '밧세바가 이름 지음'(낭독형) / 12:31 앱 본문 강제 노역 읽기 vs 주석 다수 처형 읽기
- 삼하 13:37 '암미훌'(기록형) vs 민수기 '암미훗'
- 삼하 15:27·16:3·16:12 카드는 429로 주석 조사 못함 → 보강 필요
- k 분류: 일부 hebrew 카드가 지명·인물로 바뀜(B19-25, B20-14 place, B21-8, B21-19 person, A30-27 place)
- 삼하 24:6 '다딤홋시' → 앱 본문 '닷딤홋시'로 카드 통일
- 왕상 1:27 케티브/케레 방향 BHS 확인 필요
- 왕상 7:15 기둥 높이 18규빗 vs 대하 3:15 35규빗 (카드에선 안 다룸)
- 왕상 10:28 앱 본문 '떼로 사들였다' vs 지명(구에) 읽기
- 왕상 14:13 '왜냐하면' 절이 장례에 걸리는지 확인 / 15:5 칠십인역 일부 사본에 '우리아 일' 없음
- 왕상 21:6 칠십인역 읽기 확인 필요
- 왕상 22:38 앱 본문 '매춘부' vs 해설 '창기' 용어 통일
- 왕하 3:27 '이스라엘에게 큰 진노가 내렸다' — 원문에 주체·'내렸다' 없음, 중립 표현 검토
- 왕하 5:5 '금 6,000개' 단위(세겔) 주석 여부
- 왕하 6:33 '그리고 왕이 말했다' — 원문엔 '그가'(사자/왕 해석 갈림)
- 왕하 11:6 '돌아가며' — 마싸흐 해석 확인
- 왕하 12:21 요사바드/요사갈 사본 차이
- 왕하 15:5 '별궁' — 원문 '따로 떨어진 집'(대하 26:21과 맞춤 검토)
- 왕하 16:6 앱 본문 '아람' vs 낭독형 '에돔' / 16:15 '뜻을 물어볼 때' / 16:18 '통로' 뜻 갈림
- 왕하 17:9 '몰래' vs '덮어씌움'
- 신 18:10·왕하 17:17·21:6 점술 용어 번역 불일치

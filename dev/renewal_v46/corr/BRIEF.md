# 원어 교정 판정 + 절 원어 메모 — 작업자 지침 (끝까지 읽기)

## 배경
- 우리 앱의 성경 본문은 `mz`(v45 '20대 말투' — 원어 뜻은 그대로, 말투·줄바꿈만 지금 말로)이다. **이 말투는 사용자가 고른 우리 스타일이라 그대로 지킨다.**
- `th`는 다른 팀이 만든 '원어 대조 독서판' 본문이다. 더 점잖은 말투를 쓰지만, 원어를 꼼꼼히 대조한 판이다.
- `he`는 히브리어(WLC, 모음 부호 포함). `why`는 그 팀이 원어 근거로 고친 이유. `notes`는 그 팀의 절별 원어 메모.
- 사용자 결정: "우리 v45를 유지하고, 그쪽에서 원어·의미 때문에 고친 곳만 골라 반영." 그리고 그쪽 원어 메모는 우리 앱에서 '절 번호를 누르면 보이는 원어 메모'로 쓴다.

## 할 일 (입력 파일의 모든 줄 = 한 절마다)
### 1) 교정 판정 → `fix`
`mz`가 원어(`he`)의 뜻에서 벗어난 곳이 있는지 본다(`th`·`why`·`notes`는 참고 자료).
- **고친다**: 주어·목적어·대상·지시 대상이 바뀜 / 원어에 없는 내용이 들어가 뜻이 달라짐(속마음, 이유, 뜻을 바꾸는 강조어 등) / 원어 내용이 빠짐 / 숫자·이름·지명 오류 / 부정·조건·명령·약속·질문이 바뀜 / 핵심어가 다른 개념으로 바뀜(예: 언약↔약속) / 원어와 다른 사물·제도로 옮김 / 시점·순서가 바뀌어 사건이 달라짐.
- **고치지 않는다**: 말투·어미·높임(우리 규칙: 서술은 '-했다', '-시-'는 하나님·예수님께만, 주격은 '여호와가'·'하나님이' — '께서' 금지, 대사는 관계 말투 반말·해요체·합쇼체), 줄바꿈(`\n`) 구조, 낱말 선택 취향, 문장 길이, `th`의 격식체·문단 배치. `th`가 더 점잖거나 더 길다는 이유만으로 바꾸지 않는다.
- **애매하면 고치지 않는다.** 해석이 갈리는 곳은 고치지 말고 메모로 남긴다.
- `fix`는 `mz` 전체 절을 다시 쓴 문자열이되, **필요한 낱말·구만 바꾸고 나머지는 글자 하나까지 그대로**(줄바꿈 `\n`, 따옴표 “ ” ‘ ’ 짝, 말투 유지). 고칠 게 없으면 `null`.
- `mz`가 null이면(우리 원고가 아직 없는 장) `fix`는 `null`.
- `why`: 고친 경우만, 원어 근거 한 줄(예: "לּוֹ '자기를 위해' — '직접'은 원어에 없고 뜻이 다름").

### 2) 원어 메모 → `memo`
`notes`가 있을 때만 만든다(새 메모를 지어내지 않는다). 각 메모:
`{"he": "히브리어 낱말(모음 부호 포함, he에서 그대로 복사)", "rd": "한글 발음", "m": "짧은 뜻(15자 안팎)", "t": "설명 1~3문장"}`
- **해요체로 통일**(…예요/이에요/해요/있어요/돼요/거예요). '합니다'·'-다.' 문장으로 끝내지 않는다.
- 그 팀 번역을 변호하는 말("~로 옮겼다", "참고 원고의 ~를 뺐다", "이 번역은", "본문에 만들어 넣지 않는다")은 **원어 설명으로 바꾸거나**, 우리 본문과 상관없으면 버린다. 우리 본문(`mz` 또는 `fix`)을 읽는 독자에게 맞는 설명이어야 한다.
- 사실·근거·다른 해석의 가능성은 지킨다. 새 사실·새 설교 내용을 지어내지 않는다. 사람·학자 이름 인용은 원래 메모에 있을 때만.
- `notes`의 term이 한국어뿐이면 `he`에서 해당 히브리어 낱말을 찾아 넣는다(확실하지 않으면 `he`를 빈 문자열로).
- 메모가 우리 본문과 맞지 않아 버릴 것만 남으면 `memo`는 빈 배열.

## 출력
- 파일: `/home/claude/renewal/corr/out/{묶음}.jsonl` (예: c05.jsonl). **입력 한 줄마다 출력 한 줄**, 순서 같게:
  `{"b": 1, "c": 22, "v": 8, "fix": null 또는 "새 본문", "why": "", "memo": [...]}`
- **40~50줄을 처리할 때마다 Bash로 덧붙여 저장**한다(작업이 끊겨도 남도록). 예:
  ```
  python3 - <<'PY'
  import json
  rows=[ {...}, {...} ]
  with open('/home/claude/renewal/corr/out/c05.jsonl','a',encoding='utf-8') as f:
      for r in rows: f.write(json.dumps(r,ensure_ascii=False)+'\n')
  PY
  ```
  (heredoc 안의 문자열에 작은따옴표 세 개가 나오지 않게 주의. 줄바꿈은 "\n"으로.)
- 입력은 Read 도구로 나눠 읽는다(offset/limit 60줄 정도씩). 이미 출력 파일이 있으면 그 줄 수만큼 건너뛰고 이어서 한다.

## 예시
- 창 22:8 `mz`: "아브라함이 대답했다.\n“아들아, 번제로 바칠 어린양은 하나님이 직접 마련하실 거다.”\n두 사람은 함께 걸어갔다." / `he`: …אֱלֹהִים יִרְאֶה־לּוֹ הַשֶּׂה…
  → `fix`: "아브라함이 대답했다.\n“아들아, 번제로 바칠 어린양은 하나님이 자기를 위해 마련하실 거다.”\n두 사람은 함께 걸어갔다." / `why`: "לּוֹ '자기를 위해' — '직접'은 원어에 없고 뜻이 다름"
- 삼상 3:4 `mz`: "여호와가 사무엘을 부르셨다.\n사무엘이 대답했다.\n“네, 저 여기 있어요.”" / `th`: "여호와께서 사무엘을 부르셨다. 사무엘이 “여기 있습니다” 하고 대답했다." → 말투 차이뿐 → `fix`: null.
- 메모 예: `notes` [{"hebrew":"חֶסֶד","reading":"헤세드","meaning":"곁을 지키는 신실한 사랑","explanation":"…"}] → `{"he":"חֶסֶד","rd":"헤세드","m":"곁을 지키는 신실한 사랑","t":"단순한 호감보다 관계 안에서 끝까지 책임지는 사랑을 가리켜요. …"}`

## 마지막 점검과 최종 답
- Bash(python3)로: 출력 줄 수 = 입력 줄 수, 모든 줄 JSON 파싱 OK, (b,c,v) 순서 일치, `fix`가 있으면 `mz`와 다르고 `\n` 개수가 같음, 메모 `t`가 '다.'나 '니다.'로 끝나지 않음. 틀리면 고친다(파일을 다시 써도 됨).
- 최종 답(10줄 이내): 처리한 절 수, `fix` 수, 대표 교정 5개(절 · 이유 짧게), 애매해서 남긴 곳 3개. 파일 내용을 다시 옮기지 말 것.

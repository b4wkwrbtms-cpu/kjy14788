# 설교가 말씀을 풀어가는 방식 분석 → 우리 해설 고도화 (10-25)

사용자 요청: "내가 준 모든 스킬, 그리고 네가 할 수 있는 모든 스킬을 토대로 이 설교들이 어떻게 말씀을 풀어가는지 분석하고, 우리 해설을 달 때 이들을 연구한 걸 토대로 기존 해설을 보완해서 고도화시켜."
이번 단계는 **분석**이다. 결과는 다음 단계(해설 카드 고도화)의 기준이 된다.

## 분석 틀 (설교마다 보고, 묶음 전체로 종합)
1. **본문 다루기**: 본문 범위, 읽는 순서(절 순서대로/주제별), 문맥(앞뒤 장, 책 전체 흐름) 활용, 역사·문화 배경 활용 방식.
2. **해석의 움직임**: 낱말·원어 풀이(무엇을 어떻게, 정확한가), 장면 재구성(인물의 감정·상황을 어떻게 그리나 — 본문에 있는 것/없는 것 구별), 반복어·대조·구조 포착(Alter·셈어 수사 관점으로 보면 무엇을 잡고 무엇을 놓쳤나), 성경 전체 연결(어떤 구절을 왜 끌어오나, 그리스도 중심 연결 방식), 신학 주제화.
3. **전달 장치**: 첫 질문·도입, 핵심 문장 반복, 대조·비유·예화·간증의 역할, 요약, 결단 촉구. 문장·문단 구성 특징.
4. **적용**: 본문 의미에서 적용으로 넘어가는 다리, 적용의 경계(본문이 말하는 것 vs 설교자의 확장).
5. **강점과 주의점**: 본문 이해를 실제로 깊게 하는 지점 / 해석 비약·원어 주장 오류·알레고리·문맥 이탈 가능성 — 반드시 **sid + 원고 속 짧은 인용**을 근거로.
6. **우리 해설에 가져올 것**: 해설 카드(독자의 질문 → 핵심 답 → 원어 → 장면·배경 → 성경 전체 연결 → 설교자 관점 → 적용의 경계)에 옮겨 쓸 수 있는 **구체적 기법**과 예시, 그리고 **가져오면 안 되는 것**.

## 원칙
- 설교자를 평가할 때 존중하되 정직하게. 설교자가 말한 것만 근거로(짧은 인용 + sid), 내 추론은 추론이라고 표시.
- 원어·역사 주장은 우리 원어 대조 자료(bin)로 확인할 수 있는 만큼만 판정하고, 웹 검색은 정말 필요한 곳에만 **모두 합쳐 6회 이하**. 확인 못 하면 '확인 필요'.
- 스킬 이름만 늘어놓지 말고, 그 지침의 어떤 기준으로 무엇을 봤는지 쓴다.

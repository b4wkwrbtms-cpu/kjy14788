# 설교 51편이 말씀을 풀어가는 방식 — 종합 (10-25)

자료: 장진명 목사(군산성결교회 20편 · 은평교회 8편), 유기성 목사(제자훈련 강의 23편) 원고집 수정본 전문.
방법: bible-renewal-suite의 설교 근거 검사(bible-sermon-source-audit), 본문 주해 순서(passage-exegesis), 로버트 알터의 서사 분석(구약 서사에만), 셈어 수사 구조, 신학 검토, 근거 3층 구분(evidence-grounding)을 기준으로, 우리 원어 대조 자료(히브리어·헬라어)와 대조했다. 웹 확인은 일화 몇 건에만(모두 합쳐 7회). 묶음별 상세 보고는 같은 폴더의 gs-neh / gs-life-1pet / ep / ykj-12 / ykj-34 (.md·.json).

## 1. 두 설교자의 말씀 풀이 방식
- **장진명 목사 (강해형)**: 본문을 절 순서대로 따라가며 한 문장(“나를 사용하여 주옵소서”, “처음 사랑을 버렸다”, “여호와의 명령을 따라”)을 중심축으로 세운다. 본문 안 반복어·정형구를 잘 잡는다(느 12:43 '기쁨' 5회, 느 6장 멜라카, 느 3장 양문 수미 구조, 민 9장 '여호와의 명령을 따라' 7회, 벧전 1장의 네 명령법). 번역어 오해를 바로잡는 데 강하다(충성→신실, 사업→한 일). 약점은 본문에 없는 장면·원인·속마음을 덧붙이는 것, 병행 복음서를 말없이 섞는 것, "원문 그대로"라며 풀이를 번역처럼 제시하는 것(마 25:16 '바로 가다' 등), 출처 없는 수치·통계.
- **유기성 목사 (주제·시리즈형)**: "일상의 기적", "하나님의 뜻" 같은 하나의 명제를 여러 본문으로 돌려 세운다. 강점은 대화 되받음(막 9:23 "할 수 있거든"), 같은 책 앞뒤 문맥(요 7:5, 행 18:9-10), 청중의 반론을 먼저 소리 내어 세우는 질문법이다. 원어 풀이는 3·4권 10편에서 0건. 약점은 한 구절의 범위를 모든 상황의 원리로 넓히는 것(빌 1:29, 행 3장), 다른 본문의 개념을 얹어 읽기(요 4장에 단 3장), 본문 순서와 인과 뒤바꿈(느 6:15 성벽 완성 → 9:1 회개), 번역어가 같다는 이유로 본문 잇기(롬 12:2 αἰών ≠ 마 12:39 γενεά).

## 2. 공통 강점 — 우리 해설로 가져온 12가지 (작업 지침 BRIEF 8절)
질문은 본문의 퍼즐에서 / 반복을 세어 보여 주기(구약 서사는 Leitwort·명명·서술자의 침묵) / 번역어 오해 풀기 / 같은 책·같은 저자 용례 / 문법은 보이는 사실 하나만 / 구조를 시작·끝 절로 / 앞뒤 장면 한 줄 연결(병행 본문은 차이로) / 본문·해석 갈림·설교자 상상의 세 층 표시와 설교자 관점 3단 / 이 원고집을 설교자 관점으로 활용 / 현대 비유는 하나만 표시해서 / 적용은 질문으로, 간증은 사례로 / 불확실한 수치는 나란히.

## 3. 공통 주의점 — 우리 해설에서 막는 것
본문에 없는 원인·동기·속마음·나이 채우기, 범위 이동과 보편 명제화, 본문의 침묵을 금지·원인으로 읽기, 시간절을 원인으로 읽기, 번역어가 같다고 잇기, 병행 본문 장면 섞기, "원문 그대로"식 풀이, 알레고리(시 84:5 '시온의 대로'), 출처 없는 수치·일화(호손 해임은 정권 교체 때문 — 웹 확인).

## 4. 우리 해설에 반영한 방법
- 모든 새 카드와 앞으로의 보강은 BRIEF 8절을 따른다.
- 이 설교들이 다룬 구절에 걸린 기존 카드 246장을 고도화 중(1회차 48장 완료, 25장에 설교자 관점 추가). 설교 주장이 본문·원어와 어긋나는 곳은 카드의 '다른 해석과 판단 근거'에서 근거와 함께 밝혔다(예: 롯이 떠나야만 하나님이 오신다는 읽기, 다윗이 죄를 인식조차 못 했다는 읽기, 소돔 멸망 원인을 우상숭배로 요약한 것).

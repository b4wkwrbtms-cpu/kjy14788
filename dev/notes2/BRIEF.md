# 해설 카드 새로 쓰기 — 작업자 지침 (10-18 시작: 시범 10장)

## 0. 기준
- **집필 기준은 `/home/claude/renewal/notes2/PROMPT_user.txt` (사용자가 준 '해설 집필 전용 프롬프트')다. 처음부터 끝까지 읽고 그대로 따른다.** 아래는 이 앱에 맞춘 추가 결정이다. 충돌하면 아래가 우선한다.
- **말투: 20대 독자용 해요체.** 프롬프트 예시는 합니다체지만 쓰지 않는다. 문장 끝은 -예요/-이에요/-해요/-거예요/-죠 등. 친한 선배가 차근차근 설명하듯 편하고 또렷하게. 인터넷 유행어·이모티콘·과장 감탄 금지. 학자·설교자 이름과 견해는 정확하게.
- **길이: 자유롭게, 짧지 않게.** 이해에 필요한 설명은 충분히. 다만 같은 말 반복·나열은 금지(프롬프트 11절).
- 성경 인명·지명은 **개역한글 표기**(사무엘, 엘리, 실로, 벧엘 …). 하나님 이름 YHWH는 '여호와'.
- 본문 인용은 우리 앱의 20대 말투 본문을 쓴다(아래 입력 ②). 다른 한국어 번역 문장을 인용하지 않는다.

## 1. 맡은 카드와 입력
맡은 카드 id 마다:
① 기존 카드: `/home/claude/renewal/notes2/in/{id}.json` (그쪽 팀 원본, 합니다/해라체 섞임. `_target_ref` = 이번에 기준으로 삼을 구절). 기존 내용·출처는 참고 자료이고, 사실은 다시 확인한다.
② 우리 본문: `/home/claude/bw/bout/BB/CCC.json` (BB=권 번호 2자리, CCC=장 3자리; v 배열이 절). 앞뒤 문맥도 읽는다.
③ 원어 대조: `/home/claude/bw/bin/BB/CCC.txt` (개역·WEB·원어, 모음 부호 없음). 모음 있는 히브리어: `/home/claude/renewal/app/bible/he/BB.json` (1~12권, 장→절 배열).
④ 원어 형태 정보(어근·동사 형태·인칭·수): biblehub.com 의 interlinear / 낱말 분석 페이지(WebFetch)로 확인한다. (raw.githubusercontent.com 은 이 환경에서 막혀 있음)
⑤ 사전·주석·설교: WebSearch / WebFetch 사용 가능. **한 번에 WebFetch 2개 이하, 429가 나면 30초 쉬고 다시.** 확인하기 쉬운 곳: biblehub.com (히브리어 사전 BDB·Strong, 칼뱅·매튜 헨리·길·스펄전 등 주석), ccel.org (칼뱅 주석, 스펄전 설교), spurgeon.org, gospelinlife.com·timothykeller.com (켈러), 휫필드 설교집. 네이버는 열리지 않으니 우회하지 않는다. **실제로 읽은 범위만 출처에 적는다.** 못 찾으면 지어내지 말고 memo에 '추가 연구 필요'로 남긴다.

## 2. 출력 (카드마다 파일 하나)
`/home/claude/renewal/notes2/out/{id}.json` — Write 도구로, UTF-8 JSON:
```
{
 "id": "...", "k": "hebrew|person|place|culture", "ref": "창세기 2:18",
 "q": "독자가 막히는 질문 (화면 비표시)",
 "title": "장면 속 의미가 드러나는 짧은 제목",
 "expr": [["원어 표기(모음 포함)", "한글 발음", "이 구절에서의 뜻"]],   // 인물·지명·단위도 원어 이름을 넣는다
 "core": "독자가 기억할 한 문장",
 "body": ["문단1", "문단2", "문단3"],          // 본문 해설 2~3문단(더 필요하면 4), 표지 없이 이어지는 글
 "deep": [ {"h": "실제 용례와 당시 배경", "p": ["…"]},
           {"h": "시제·문법이 보여 주는 의미", "p": ["…"]},
           {"h": "설교자·주석가의 관점", "p": ["…"]},
           {"h": "다른 해석과 판단 근거", "p": ["…"]} ],   // 이 카드에 필요한 것만, 순서 유지
 "src": [ {"t": "저자 · 자료명 · 본문/쪽/단락 · 실제 확인한 범위", "u": "https://… (없으면 빈 문자열)"} ],
 "memo": "편집자 확인 사항 (독자 비표시): 확인 못 한 점, 해석적 추론, 추가 연구거리"
}
```
- 히브리어는 모음 부호가 있는 형태로(입력 ③의 he 파일 또는 사전에서 확인).
- 설교자 관점 한 항목은 프롬프트 8절 구조(누구·어느 자료 → 무엇을 강조 → 본문 근거 → 본문 의미와 적용의 경계 → 독자에게 주는 이해)로 3~5문장 이상.
- 직접 인용은 원문을 실제로 읽은 경우에만, 그 외는 '요약'임을 src 에 밝힌다.

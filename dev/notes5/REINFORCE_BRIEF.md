# 설교자 보강 지침 (11-18 밤) — 이미 쓴 카드에 빠진 설교자·주석 채우기
먼저 /home/claude/renewal/notes5/WRITE_BRIEF_v2.md 를 끝까지 읽는다(특히 '11-18 밤' 두 절, 말투·3단 형식·src·memo 규칙).
맡은 카드(/home/claude/renewal/notes3/out/{id}.json)는 검색 한도 때문에 스펄전·로이드존스·켈러(일부는 주석도) 검색을 못 한 채 쓰였다.
1. 카드와 memo를 읽고 무엇이 빠졌는지 확인한다(memo의 "못 찾아봄/한도/추가 연구").
2. 그 절·단락을 다룬 설교를 순서대로 찾는다: 스펄전(spurgeon.org·ccel·spurgeongems) → 로이드존스(mljtrust.org) → 켈러 공개 자료(gospelinlife 등). 꾸러미(/home/claude/renewal/notes5/pk/{id}.json, 없으면 생략)의 keller_private가 있으면 그 파일을 읽어 요약으로 넣는다(문장 옮기지 않기). 주석이 아예 없던 카드는 전통이 다른 주석 2~3개(칼뱅 등)를 먼저 채운다.
3. 실제로 읽은 것만 deep의 '설교자·주석가의 관점'에 3단(읽기 → 본문 근거 → 적용의 경계)으로 덧붙이고 src에 추가한다. 기존 내용은 틀린 곳만 고친다. 직접 인용은 쓰지 않는다(요약).
4. 못 찾으면 memo에 "[보강 11-18] 스펄전·로이드존스·켈러 검색함 — 이 절 설교 없음"으로 바꿔 적는다. 찾았으면 "[보강 11-18] ○○ 추가".
5. WebSearch는 합쳐 14회 이하. 같은 단락 카드는 검색을 함께 쓴다. 한도 소진 오류가 나면 거기서 멈추고 못 한 카드 id를 보고한다.
6. JSON 열림·해요체·책 이름 붙은 장:절을 점검한다.
